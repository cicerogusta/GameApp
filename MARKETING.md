## 🎬 Social Media Strategy

### TikTok / YouTube Shorts (Most Important)

**Why:** Roguelikes thrive on TikTok. Algorithm favors game content.

#### Hook 1: "Impossible Spawn"
```
Duration: 15 seconds
Script:
  0-2s: Game starts, 10+ enemies spawn
  2-4s: Player barely dodges left/right
  4-8s: Rapid combat montage, enemies die
  8-12s: Massive echo shower, golden glow
  12-15s: Text: "VOID EATER | Steam Soon"
Music: Intense synth drop
```
**Hook:** "Can you survive this?" / "Hardest difficulty"

#### Hook 2: "The Echo System"
```
Duration: 12 seconds
Script:
  0-3s: Enemy dies, echo appears
  3-6s: Show 3 echo choice visual (temporary/shield/permanent)
  6-9s: Player chooses, gets boost, defeats 5 more enemies
  9-12s: "Every choice matters. VOID EATER coming to Steam"
Music: Satisfying SFX + background track
```
**Hook:** "This mechanic is genius" / "New roguelike mechanic"

#### Hook 3: "Permanent Progress"
```
Duration: 12 seconds
Script:
  0-4s: Player dies, "RUN OVER" screen
  4-8s: Upgrade screen shows permanent unlocks
  8-12s: "Die to get stronger. Permanently. VOID EATER"
Music: Motivational synth
```
**Hook:** "This game respects your time" / "No grind"

#### Hook 4: "Boss Fight"
```
Duration: 15 seconds
Script:
  0-3s: Regular wave gameplay
  3-5s: Screen shake, boss appears (Echo Sovereign)
  5-10s: Intense boss fight, player barely wins
  10-15s: Victory screen + "VOID EATER | Steam Wishlist Now"
Music: Epic orchestral hit + synth
```
**Hook:** "That boss fight was insane"

#### Hook 5: "Speedrun Potential"
```
Duration: 20 seconds
Script:
  0-5s: Super fast gameplay clip (2x speed)
  5-10s: Perfect dodge sequence
  10-15s: Optimal upgrade sequence
  15-20s: Victory in 3 minutes "WR ATTEMPT: VOID EATER"
Music: Fast-paced electronic
```
**Hook:** "Speedrunners NEED this game"

### Posting Schedule
- **Minimum:** 3 posts per week
- **Ideal:** Daily during launch week
- **Post Times:** 
  - 6 PM (primetime)
  - 10 AM (morning gaming)
  - 2 AM (late night gamers)
